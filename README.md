# Jose Rivera Tech — Accesorios Tecnológicos & Repuestos de Conveniencia

Single Page Application (SPA) ultrarrápida, modular y orientada a conversión para isla/local comercial de tecnología en Colombia.

- **WhatsApp Oficial:** `+57 301 476 8000` (`301 4768000`)
- **Estética de Marca:** Dorado y Negro Cyber Luxury (Oro Metálico `#D4AF37` y Negro Obsidian `#08080A`).
- **Arquitectura:**
  - `index.html`: Estructura semántica, filtros facetados, catálogo dinámico y modal de checkout.
  - `css/styles.css`: Estilos oscuros, micro-interacciones, shimmer gold y diseño 100% responsivo.
  - `js/products.js`: Catálogo categorizado (Carga y Cables, Audio y Manos Libres, Controles y Repuestos, Protección y Gadgets).
  - `js/cart.js`: Carrito reactivo con persistencia en `localStorage`.
  - `js/filters.js`: Motor de búsqueda en tiempo real y filtrado facetado por compatibilidad.
  - `js/whatsapp.js`: Generador de payload estructurado para cierre de ventas por WhatsApp.
